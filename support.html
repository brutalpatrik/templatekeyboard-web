Getting Started

  1. Install Template Keyboard from App Store
  2. Open the app and create your first template
  3. Define variables (like $name, $date)
  4. Enable the keyboard in Settings → General → Keyboard → Keyboards
  5. Allow Full Access (required for the keyboard to read templates)

FAQ

Why does the keyboard need "Allow Full Access"?

The keyboard needs this permission to read your templates from the shared app storage (App Groups).

How do I create a variable?

In the Variables tab, tap the + button and enter a key (like "name" for $name). Add preset values or allow custom input.

Can I share templates?

Yes! Use Settings → Export data to save templates as JSON, then share the file with your team.
